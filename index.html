Ekaros

Experimentation for teams that ship fast. Set up A/B tests by talking to your LLM.

An LLM-native experimentation platform. Ekaros plugs into any LLM through the Model Context Protocol (MCP), so developers describe an experiment, let the LLM register it and generate the code, and then ask the LLM for the results. It tracks events across frontend and backend, with no new dashboard to learn.

  • Go, Kafka and Redis event pipeline, with ClickHouse + PostgreSQL for analytics
  • Onboarding, experiment journeys, and analytics dashboards with event counts and latency distributions
  • SDKs published to PyPI (Django middleware with API latency and memory metrics) and npm (React)
  • Use cases demoed end to end: A/B testing two ways of showing job listings, and comparing LLMs on user satisfaction

USC · Multimedia Systems DesignSpring 2025

Ultra-high-resolution panoramas from video

Point a phone camera, pan around, and get one huge stitched image from the footage.

A two-stage pipeline built by a three-person team for CSCI 576. V2 extracts frames from each video in its own thread, estimates camera motion, keeps only the frames worth stitching and orders them by position before handing them to OpenCV's stitcher. If the stitcher times out, the pipeline falls back to V1, a hand-built path: homography estimation, inlier-ratio and degeneracy checks, then warping, blending and border cropping.
